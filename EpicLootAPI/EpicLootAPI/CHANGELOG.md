**1.0.0**
- First standalone release of the Epic Loot API, as a DLL to bundle into your plugin or as source files to copy in.
- Mods can read Epic Loot's tooltip information for an item, change it, or take over drawing the inventory tooltip.
- Container mods can tell Epic Loot which items are their containers and check when a key press is meant for shard slots.
- Mods can create an item or runestone carrying exactly the enchantments and set they choose.
